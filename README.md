<h1 align="center">📱 Android App Project</h1>

<p align="center">
A modern Android application built using <b>Android Studio</b>, <b>Gradle</b>, and <b>Kotlin</b>.
</p>

<hr>

<h2>📌 Project Overview</h2>

<p>
This repository contains an Android application project configured with Gradle.
The project uses AndroidX libraries and modern Android development tools.
It demonstrates Android development concepts including UI design,
Gradle build configuration, and modular project structure.
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
<li>📱 Modern Android UI</li>
<li>⚡ Fast Gradle build system</li>
<li>🧩 Modular project configuration</li>
<li>🔧 Easy to customize and extend</li>
<li>📦 AndroidX support libraries</li>
</ul>

<hr>

<h2>📂 Project Structure</h2>

<pre>
AndroidProject/
│
├── app/                # Main application module
├── gradle/             # Gradle wrapper files
├── build.gradle.kts    # Project build configuration
├── settings.gradle.kts # Project settings
├── gradle.properties   # Gradle configuration
└── README.md
</pre>
